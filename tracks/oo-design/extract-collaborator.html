Extract a collaborator

{% capture lesson_body %} ## Pulling responsibilities apart The fix is to split each job into its own class. `Invoice` keeps the money. Rendering and delivery become collaborators. ```ruby class InvoiceRenderer def initialize(invoice); @invoice = invoice; end def to_pdf; ... end end class InvoiceMailer def initialize(invoice, transport: SMTP); ... end def deliver_to(customer); ... end end ``` Now `Invoice` only changes when invoicing rules change. `InvoiceRenderer` only changes when the PDF style changes. {% endcapture %} {{ lesson_body | markdownify }}
