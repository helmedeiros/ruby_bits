Inject collaborators

{% capture lesson_body %} ## Dependency injection When a class hard-codes `Sms.new`, it knows the class name. Rename `Sms` and the dependent class breaks too. ```ruby # Hard-coded — tight coupling class OrderConfirmation def deliver(order) Sms.new.send(order.phone, "order #{order.id} confirmed") end end ``` Pass the dependency in: ```ruby class OrderConfirmation def initialize(channel: Sms.new) @channel = channel end def deliver(order) @channel.send(order.phone, "order #{order.id} confirmed") end end ``` Now `OrderConfirmation` only knows it has *something that responds to `send`*. Swap in an `Email`, a `Push`, or a test double — no change to `OrderConfirmation`. {% endcapture %} {{ lesson_body | markdownify }}
