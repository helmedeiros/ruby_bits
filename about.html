man rubybits

NAME
       rubybits — interactive ruby learning environment

SYNOPSIS
       open https://helmedeiros.github.io/ruby_bits

DESCRIPTION
       rubybits ships short lessons grouped into modules, with
       runnable activities checked by a sandboxed ruby subprocess
       in the Rails companion app. This GitHub Pages site is the
       static showcase — the dynamic platform runs server-side.

SEE ALSO
       irb(1), ruby(1), pickaxe(7)
