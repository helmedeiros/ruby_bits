Hashes

{% capture lesson_body %} ## Hashes Hashes map keys to values. Any object can be a key, but symbols are most common: ```ruby user = { name: "alice", age: 30 } user[:name] # => "alice" user[:role] = :admin ``` A handy trick: `Hash.new(0)` returns `0` for any missing key, which makes counting trivial. {% endcapture %} {{ lesson_body | markdownify }}
