Strings and symbols

{% capture lesson_body %} ## Strings and symbols A **string** is a sequence of characters. Strings are mutable and can be built dynamically with interpolation: ```ruby name = "alice" "hello, #{name}" # => "hello, alice" ``` A **symbol** is an interned identifier — immutable, unique, and cheap to compare: ```ruby :name # always the same object ``` Use symbols for fixed identifiers (hash keys, states, types). Use strings for human-facing text or anything that varies. {% endcapture %} {{ lesson_body | markdownify }}
