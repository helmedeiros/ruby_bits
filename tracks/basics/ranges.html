Ranges

{% capture lesson_body %} ## Ranges A **range** is a value representing a contiguous sequence — `1` to `10`, or `"a"` to `"z"`. Ranges are written with two dots (`..`) for inclusive or three dots (`...`) for "up to but not including". ### Literal syntax ```ruby (1..10) # 1, 2, ..., 9, 10 — inclusive (1...10) # 1, 2, ..., 9 — exclusive (10 is left out) ("a".."e") # "a", "b", "c", "d", "e" ``` ### Membership ```ruby (1..10).include?(5) # => true (1..10).include?(11) # => false ("a".."e").include?("c") # => true ``` ### Iteration Ranges respond to `each`, just like arrays: ```ruby (1..3).each { |n| puts n } # 1 # 2 # 3 ``` Convert to an array with `.to_a`: ```ruby (1..5).to_a # => [1, 2, 3, 4, 5] ('a'..'c').to_a # => ["a", "b", "c"] ``` ### Common uses Ranges show up everywhere — `for` loops, array slicing, `between?`, `case`-`when` matching: ```ruby letters = ('a'..'z').to_a # whole alphabet arr = [10, 20, 30, 40, 50] arr[1..3] # => [20, 30, 40] (slice by range) ``` ### Pitfall: `...` is easy to miss The difference between `..` and `...` is one character. Read carefully when debugging off-by-one errors: ```ruby (1..5).size # => 5 (1...5).size # => 4 ``` {% endcapture %} {{ lesson_body | markdownify }}
