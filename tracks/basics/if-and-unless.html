if and unless

{% capture lesson_body %} ## if and unless `if` runs the body when the condition is truthy; `unless` runs it when the condition is falsy. Both are expressions — they return the value of the last evaluated branch. ```ruby status = if user.admin? "ALL POWER" else "regular" end ``` The inline form is great for guard clauses: ```ruby return :ignored unless params[:id] ``` {% endcapture %} {{ lesson_body | markdownify }}
