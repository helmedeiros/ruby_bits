Raising exceptions

{% capture lesson_body %} ## Raising When a method cannot return a sensible value, raise rather than returning a sentinel: ```ruby def withdraw!(amount) raise ArgumentError, "amount must be > 0" unless amount > 0 @balance -= amount end ``` Use the right ancestor class — `ArgumentError`, `KeyError`, `RuntimeError` — so callers can rescue with intent. {% endcapture %} {{ lesson_body | markdownify }}
