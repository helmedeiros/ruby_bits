Hash arguments remove order coupling

{% capture lesson_body %} ## From positional to keyword arguments Positional arguments tie callers to the order: ```ruby def initialize(name, age, role) ``` Every caller now hard-codes `(name, age, role)`. Swap two arguments and you break them all. ```ruby def initialize(name:, age:, role:) @name, @age, @role = name, age, role end ``` Callers list args by name, in any order. You can add fields without breaking existing call sites. {% endcapture %} {{ lesson_body | markdownify }}
