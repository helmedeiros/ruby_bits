Find the duck

{% capture lesson_body %} ## Duck typing A `case` that switches on class is almost always a duck type waiting to surface: ```ruby def render(report) case report when DailyReport then DailyRenderer.new.render(report) when WeeklyReport then WeeklyRenderer.new.render(report) when MonthlyReport then MonthlyRenderer.new.render(report) end end ``` Replace by giving each report its own `render` method: ```ruby def render(report) report.render end ``` Now adding a new report type doesn't require editing `render`. {% endcapture %} {{ lesson_body | markdownify }}
