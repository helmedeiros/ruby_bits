Truthy and falsy

{% capture lesson_body %} ## Truthy and falsy Ruby treats **only `false` and `nil`** as falsy. Everything else — including `0`, `""`, and `[]` — is truthy. ```ruby puts "yes" if 0 # prints puts "yes" if "" # prints puts "yes" if [] # prints puts "yes" if nil # nothing puts "yes" if false # nothing ``` This trips up people coming from C or Python — be deliberate. {% endcapture %} {{ lesson_body | markdownify }}
