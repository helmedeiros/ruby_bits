Spotting an SRP violation

{% capture lesson_body %} ## Single Responsibility Principle A well-designed class makes change cheap. The first test is: *can you describe its job in one sentence?* ```ruby class Invoice def initialize(customer, lines) @customer = customer @lines = lines end def total @lines.sum { |l| l[:qty] * l[:price] } end def to_pdf # render headers, draw the table, embed company logo, ship to file end def email_to_customer # build HTML body, attach PDF, hit the SMTP server end end ``` `Invoice` calculates money, renders PDFs, and sends mail. Three reasons to change. Change the SMTP layer and you risk breaking totals. {% endcapture %} {{ lesson_body | markdownify }}
