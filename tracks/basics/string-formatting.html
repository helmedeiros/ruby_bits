String formatting

{% capture lesson_body %} ## String formatting Interpolation (`"#{value}"`) covers most cases, but sometimes you want padding, decimal places, or column alignment. Ruby has three tools for that. ### `String#%` — printf-style Same format specifiers as C's printf. Apply with the `%` operator: ```ruby "name: %s, age: %d" % ["alice", 30] # => "name: alice, age: 30" "%5d" % 42 # => " 42" (right-pad to width 5) "%-5d" % 42 # => "42 " (left-pad) "%.2f" % 3.14159 # => "3.14" "%08.2f" % 3.14 # => "00003.14" ``` Common specifiers: - `%s` — string (calls `.to_s`) - `%d` / `%i` — integer - `%f` — float - `%x` — hex - `%5d` — width 5 - `%.2f` — 2 decimals - `%-5s` — left-align ### `Kernel#format` (alias `sprintf`) Same syntax, function form. Some people find it more readable: ```ruby format("%5d", 42) # => " 42" sprintf("%.2f", 3.14159) # => "3.14" ``` ### Multi-value with hash interpolation When you have several values, the `%{name}` form pairs with a hash — much clearer than positional `%s %d`: ```ruby "name: %{name}, age: %{age}" % { name: "alice", age: 30 } # => "name: alice, age: 30" ``` ### When to use what - **Plain interpolation** for general string building. - **`%`/`format`** when you need padding, precision, or column alignment. - **`%{...}`** when you have many fields and want them named. {% endcapture %} {{ lesson_body | markdownify }}
