Conditional assignment

{% capture lesson_body %} ## Conditional assignment `||=` assigns only if the variable is `nil` or `false`. It is the canonical memoisation idiom in ruby. ```ruby def projects @projects ||= Project.where(owner: self).to_a end ``` Be careful: `||=` rejects any falsy value, not just `nil`. If `false` is a legitimate value, use `defined?` instead. {% endcapture %} {{ lesson_body | markdownify }}
