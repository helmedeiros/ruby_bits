Constants

{% capture lesson_body %} ## Constants A **constant** is an identifier that starts with an uppercase letter. Ruby treats it as a name you don't expect to change. ### Syntax ```ruby PI = 3.14159 MAX_RETRY = 3 COLORS = %w[red green blue] ``` Class and module names are also constants: ```ruby class User; end # `User` is a constant module Auth; end # so is `Auth` ``` ### "Constant" doesn't mean "frozen" Ruby will *warn* you if you reassign a constant, but it lets you do it. And the *value* of a constant is mutable unless you freeze it: ```ruby COLORS = %w[red green blue] COLORS << "yellow" # works! COLORS is now 4 elements COLORS = ["only red"] # warns: "already initialized constant" ``` To make a constant actually immutable, freeze its value: ```ruby COLORS = %w[red green blue].freeze COLORS << "yellow" # FrozenError ``` ### Scoping Top-level constants are global. Constants defined inside a class or module belong to that namespace and you access them with `::`: ```ruby class Order STATUSES = [:pending, :paid, :shipped].freeze end Order::STATUSES # => [:pending, :paid, :shipped] ``` ### Naming conventions - **`SCREAMING_SNAKE_CASE`** for true constants (numbers, strings, lists). - **`PascalCase`** for class and module names. ### When to use a constant Anywhere a magic value would otherwise appear inline: ```ruby # bad raise "max retries hit" if retries > 3 # good MAX_RETRIES = 3 raise "max retries hit" if retries > MAX_RETRIES ``` {% endcapture %} {{ lesson_body | markdownify }}
