Regular expressions

{% capture lesson_body %} ## Regular expressions A **regular expression** (regex) is a small language for describing string patterns. Ruby builds them with `/.../` literals. ### Matching ```ruby "hello world" =~ /world/ # => 6 (index of match) "hello world" =~ /bye/ # => nil (no match) "user@x.com".match?(/@/) # => true (boolean check) ``` `=~` returns the index of the match or `nil`. `match?` is a clean true/false test (Ruby 2.4+) — prefer it when you don't need the data. ### Character classes ```ruby /[aeiou]/ # any vowel /[0-9]/ # any digit (same as \d) /[a-zA-Z]/ # any letter /[^0-9]/ # NOT a digit (^ inside [] negates) ``` ### Common shortcuts - `\d` — digit - `\w` — word char (letter, digit, underscore) - `\s` — whitespace - `\D`, `\W`, `\S` — negations ### Quantifiers - `*` — zero or more - `+` — one or more - `?` — zero or one - `{3}` — exactly 3 - `{2,4}` — between 2 and 4 ```ruby /\A\d{3}-\d{4}\z/ # ###-#### (whole string) /^http/ # starts with "http" (line) ``` ### Capture groups Parentheses **capture** parts of the match. Use `match` to get them: ```ruby m = "alice@example.com".match(/(\w+)@(\w+)/) m[0] # => "alice@example" (full match) m[1] # => "alice" (1st group) m[2] # => "example" (2nd group) ``` ### Replace with `gsub` ```ruby "hello world".gsub(/o/, "0") # => "hell0 w0rld" "a 1, b 2".gsub(/\d+/) { |n| n.to_i * 2 } # => "a 2, b 4" ``` ### Anchors - `^` / `$` — start / end of **line** - `\A` / `\z` — start / end of **string** Prefer `\A` / `\z` over `^` / `$` when validating a whole input — multi-line strings can fool you otherwise. {% endcapture %} {{ lesson_body | markdownify }}
