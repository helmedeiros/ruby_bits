Defining methods

{% capture lesson_body %} ## Defining methods ```ruby def square(n) n * n end square(4) # => 16 ``` Arguments can have defaults, can be splatted (`*rest`), and can be keyword-style (`name:`). Keyword args remove ordering coupling between callers and definition. ```ruby def shift(point, by: 1) point + by end shift(10, by: 3) # => 13 shift(10) # => 11 ``` {% endcapture %} {{ lesson_body | markdownify }}
