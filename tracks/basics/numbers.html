Numbers

{% capture lesson_body %} ## Numbers Ruby has two number types you'll meet first: **integers** and **floats**. They look similar but behave differently in subtle ways. Let's walk through the basics and then look at the gotchas. ### Integers Whole numbers, with no decimal point: ```ruby 42 -17 1_000_000 # underscores are allowed for readability ``` All the arithmetic you'd expect: ```ruby 2 + 3 # => 5 10 - 4 # => 6 7 * 6 # => 42 20 / 4 # => 5 17 % 5 # => 2 (modulo / remainder) 2 ** 10 # => 1024 (exponent) ``` ### Floats Decimal numbers: ```ruby 3.14 -0.5 1.5e3 # scientific notation: 1500.0 ``` Floats follow the IEEE-754 standard, so you get the usual floating-point quirks: ```ruby 0.1 + 0.2 # => 0.30000000000000004 (not exactly 0.3) ``` For money or anything where exactness matters, use `BigDecimal` or work in cents (integers). ### Integer division Here's the most common surprise. Dividing two integers in Ruby **truncates** — you get an integer back, not a float: ```ruby 5 / 2 # => 2 (not 2.5!) 7 / 3 # => 2 -7 / 3 # => -3 (rounds toward negative infinity) ``` To get a float result, **make at least one operand a float**: ```ruby 5 / 2.0 # => 2.5 5.0 / 2 # => 2.5 5.fdiv(2) # => 2.5 (float division explicitly) ``` ### Useful methods ```ruby -7.abs # => 7 3.14.round # => 3 3.14.round(1) # => 3.1 3.14.floor # => 3 3.14.ceil # => 4 42.to_s # => "42" "42".to_i # => 42 "3.14".to_f # => 3.14 42.even? # => true 7.odd? # => true 7.zero? # => false 0.zero? # => true ``` ### Predicates and ranges `between?` and the comparison family are common: ```ruby age = 25 age.between?(18, 65) # => true age >= 18 && age < 65 # equivalent ``` {% endcapture %} {{ lesson_body | markdownify }}
