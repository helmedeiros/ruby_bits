{% capture lesson_body %} ## Default with `||` ```ruby name = params[:name] || 'anonymous' ``` `name` is `params[:name]` when present, otherwise `'anonymous'`. The reader sees: "primary, fallback." Watch out for `false` — `false || 'x'` is `'x'`. If `false` is a meaningful value, use `params.fetch(:flag, true)` instead. {% endcapture %} {{ lesson_body | markdownify }}
