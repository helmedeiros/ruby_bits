Hashes

{% capture lesson_body %} ## Hashes A **hash** maps keys to values — like a dictionary. Order is preserved (since Ruby 1.9) and any object can be a key, but symbols are most common. ### Creating and reading ```ruby user = { name: "alice", age: 30, role: :admin } user[:name] # => "alice" user[:age] # => 30 user[:missing] # => nil (no error, just nil) ``` The `{ name: "alice" }` shorthand is for symbol keys. Equivalent older syntax: `{ :name => "alice" }`. ### Writing and updating ```ruby user[:role] = :viewer # set or overwrite user[:email] = "a@x" # add a new key user.delete(:age) # remove a key user.size # => 2 user.keys # => [:name, :role, :email] user.values # => ["alice", :viewer, "a@x"] ``` ### Default values By default, missing keys return `nil`. But sometimes you want a *non-nil* default — e.g. counting things: ```ruby counts = Hash.new(0) # any missing key returns 0 counts[:a] += 1 counts[:a] += 1 counts[:b] += 1 counts # => {a: 2, b: 1} ``` Without `Hash.new(0)`, the first `counts[:a] += 1` would crash because `nil + 1` is an error. ### Iterating ```ruby user.each do |key, value| puts "#{key}: #{value}" end ``` Hashes have the same `map`, `select`, `reduce` family as arrays, but each block gets `key, value`. {% endcapture %} {{ lesson_body | markdownify }}
