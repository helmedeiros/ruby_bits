Iteration methods

{% capture lesson_body %} ## Iteration methods Most other languages give you `for` and `while`. Ruby has those too, but `for` is rarely used in real code. Idiomatic Ruby uses **methods on the collection** itself, with a block. ### `times` Run a block N times: ```ruby 3.times { puts "ping" } 3.times { |i| puts "iteration #{i}" } # i goes 0..2 ``` ### `each` The bread-and-butter iterator. Available on arrays, hashes, ranges, and anything that includes `Enumerable`. ```ruby [1, 2, 3].each { |n| puts n } (1..3).each { |n| puts n } { a: 1, b: 2 }.each { |k, v| puts "#{k}=#{v}" } ``` ### `while` and `until` When you don't know how many iterations you'll need: ```ruby while balance > 0 balance -= withdraw end until queue.empty? process(queue.shift) end ``` ### `loop` Infinite loop — pair with `break` to exit: ```ruby loop do job = next_job break unless job job.run end ``` ### Breaking and skipping Inside any of these, you can use: - `break` — exit the loop - `next` — skip to the next iteration - `redo` — re-run the current iteration (rare) ```ruby (1..10).each do |n| next if n.even? # skip even break if n > 7 # stop at 7 puts n # prints 1, 3, 5, 7 end ``` ### Pitfall: prefer `each` over `for` Ruby has `for x in arr` syntax, but it leaks the loop variable into the enclosing scope, while `each` doesn't. Stick with `each`. {% endcapture %} {{ lesson_body | markdownify }}
