unless — the negated if

{% capture lesson_body %} ## unless `unless` reads cleaner than `if !condition` for negative checks. ```ruby # verbose raise 'must be signed in' if !current_user # idiomatic raise 'must be signed in' unless current_user ``` ### Rules of thumb - Use it for single-clause negatives. - Avoid pairing it with `else` — the reader has to invert twice. - Avoid mixing it with `&&` — extract the negative condition into a predicate. {% endcapture %} {{ lesson_body | markdownify }}
