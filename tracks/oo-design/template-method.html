Template method

{% capture lesson_body %} ## Template method The parent defines the *shape* of an algorithm and leaves specific steps to subclasses, often with `raise NotImplementedError` as a contract for "you must implement this": ```ruby class Report def render "#{header}\n#{body}\n#{footer}" end def header; "REPORT — #{Time.now.year}"; end def footer; "— end —"; end def body raise NotImplementedError, "#{self.class} must implement #body" end end ``` Subclasses only fill in the gaps: ```ruby class SalesReport < Report def body; "sales were up 12%"; end end ``` {% endcapture %} {{ lesson_body | markdownify }}
