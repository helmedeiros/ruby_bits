Composition over inheritance

{% capture lesson_body %} ## Composition over inheritance When you reach for a superclass, ask: is the new class genuinely an *is-a* specialization, or just sharing some behavior? For sharing behavior across unrelated objects, compose: ```ruby class Order def initialize(items:, pricer:) @items, @pricer = items, pricer end def total @pricer.total(@items) end end class FixedPricer def total(items); items.sum { |i| i[:price] } end end class TaxedPricer def initialize(rate); @rate = rate; end def total(items); items.sum { |i| i[:price] } * (1 + @rate); end end ``` `Order` doesn't know how prices are computed — it just asks its pricer. Swap pricers freely; `Order` is untouched. {% endcapture %} {{ lesson_body | markdownify }}
