if and unless

{% capture lesson_body %} ## if and unless ### if `if` runs the body when the condition is truthy: ```ruby if score >= 60 puts "you passed" else puts "study more" end ``` You can have multiple branches with `elsif`: ```ruby if score >= 90 grade = "A" elsif score >= 80 grade = "B" elsif score >= 70 grade = "C" else grade = "F" end ``` ### if as an expression A surprise for newcomers: `if` *returns* a value. The whole block is an expression, so you can assign its result: ```ruby grade = if score >= 90 then "A" elsif score >= 80 then "B" else "F" end ``` The value of the chosen branch becomes the value of the whole `if`. There's no need for a temporary variable. ### Inline (modifier) if For a single-line body, you can put `if` at the end: ```ruby puts "you passed" if score >= 60 ``` This reads as "do X, if condition". Great for guard clauses and short side effects. ### unless: negative if `unless` runs the body when the condition is **falsy** — basically a `if !`: ```ruby unless logged_in redirect_to_login end # same as: if !logged_in redirect_to_login end ``` And the inline form: ```ruby return :guest unless current_user ``` A rule of thumb: use `unless` for single negative conditions (`unless user`). Avoid `unless` with `else` (it makes the reader invert the meaning twice). ### Ternary For very short conditional values, Ruby has the same `? :` syntax as C: ```ruby result = score >= 60 ? "pass" : "fail" ``` Don't nest these — for anything beyond one level use a full `if`. {% endcapture %} {{ lesson_body | markdownify }}
