Arrays

{% capture lesson_body %} ## Arrays An **array** is an ordered list of values. Indexes start at `0`. Arrays can hold anything — numbers, strings, even other arrays — and they can mix types. ### Creating and indexing ```ruby fruits = ["apple", "banana", "cherry"] fruits[0] # => "apple" fruits[1] # => "banana" fruits[2] # => "cherry" fruits[3] # => nil (out of bounds is nil, not an error) ``` Negative indexes count from the end: ```ruby fruits[-1] # => "cherry" (last item) fruits[-2] # => "banana" ``` Useful methods: ```ruby fruits.first # => "apple" fruits.last # => "cherry" fruits.size # => 3 fruits.empty? # => false fruits.include?("banana") # => true ``` ### Adding and removing ```ruby fruits << "date" # append (mutates) fruits.push("elderberry") # same as << fruits.pop # removes & returns last fruits.shift # removes & returns first fruits.unshift("apricot") # prepend ``` ### Iterating The most common loop pattern in Ruby is `.each`: ```ruby fruits.each do |fruit| puts fruit.upcase end ``` When you want to transform every element into a new array, use `.map`: ```ruby lengths = fruits.map { |f| f.length } # => [5, 6, 6] ``` When you want to keep only some elements, use `.select`: ```ruby short = fruits.select { |f| f.length < 6 } # => ["apple"] ``` When you want a single value out of a collection (sum, product, …), use `.reduce`: ```ruby [1, 2, 3, 4].reduce(0) { |sum, n| sum + n } # => 10 ``` These four — `each`, `map`, `select`, `reduce` — solve most collection problems you'll ever face. {% endcapture %} {{ lesson_body | markdownify }}
